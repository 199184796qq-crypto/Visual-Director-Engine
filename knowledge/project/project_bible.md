# VDE Project Bible
# 项目视觉圣经 v1.0


================================================

# 核心定位


Project Bible 是 VDE 的长期视觉记忆系统。


作用：

定义一个项目固定视觉规则。


所有后续：

- 图片
- 视频
- 分镜
- 海报
- 产品图

必须遵守。


================================================

# Project Bible Structure


项目视觉规范包含：


1. Project Identity

2. World Setting

3. Character Rules

4. Visual Style

5. Camera Rules

6. Lighting Rules

7. Color Rules

8. Material Rules

9. Composition Rules

10. Forbidden Rules



================================================

# 01 Project Identity
# 项目身份


记录：


Project Name:

项目名称


Purpose:

用途：

- 电影
- 广告
- 品牌
- 游戏
- 短视频



Genre:

类型：

- 写实
- 科幻
- 武侠
- 商业


Target Feeling:

目标感觉。

Premium cinematic advertisement,
warm family emotion.
